# Irfan Raza Portfolio — V8 Character Hero

This is a GitHub Pages-ready static website portfolio for Irfan Raza.

## New hero interaction
- The hero section keeps the same overall style, but now includes an interactive character made from the supplied JPEG sequence in `PPG.zip`.
- As the mouse moves across the page, the character updates frames so it appears to look toward the pointer.
- The hero still keeps the cinematic dark background, the editor portrait, the main headline and the five 9:16 showreel cards.

- About Me

- Contact

## GitHub Pages upload
1. Extract this ZIP.
2. Upload **all files and folders inside it** to the root of your GitHub repository.
3. In GitHub Settings → Pages, choose **Deploy from a branch** → `main` → `/(root)`.
4. Save and wait for deployment.

No npm install is required.
